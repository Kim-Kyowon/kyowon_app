# 📱 나만의 전용 포털 허브 (My App Hub)

개인 라이프스타일과 자산 관리를 단일 웹앱에서 안전하고 효율적으로 관리할 수 있는 **모바일 퍼스트 개인 전용 PWA(Progressive Web App)**입니다.

GitHub Pages를 통해 모바일 스마트폰에 일반 네이티브 앱처럼 설치하여 사용할 수 있습니다.

---

## 🌟 주요 서비스 구성

### 1. 💰 자산현황 (`/asset`)
* **총 순자산 모니터링:** 총자산에서 대출(부채)을 차감한 실시간 순자산 계산
* **노후 연금자산 별도 표기:** 개인연금, 회사지원 연금, 퇴직연금 DC, IRP 등 노후 대비 연금자산을 괄호 안에 자동 집계 표기
* **5대 자산 & 부채 카테고리:**
  * **예금:** 우리은행 계좌, 주거래 입출금, CMA 등
  * **적금:** 정기 적금, 주택 청약 등
  * **주식:** 개인연금, 퇴직연금 DC/IRP, ISA 등
  * **가상자산:** 업비트 계좌 등
  * **부동산:** 거주 부동산, 보증금 등
  * **대출:** 주택담보대출, 신용대출 등 (순자산에서 자동 차감)
* **스마트 편의 기능:**
  * 숫자 입력 시 **천 단위 자동 콤마(`,`)** 실시간 기록
  * 모바일 친화적 **숫자 전용 키패드(`inputmode="numeric"`)** 지원
  * 상단 **[+ 자산 추가]** 버튼을 통한 원터치 항목 등록 모달
  * 일자별 순자산 변화를 기록하는 **월별 자산 추이 스냅샷**

### 2. 💳 카드 실적관리 (`/card`)
* **카드별 목표 실적 추적:** 카드별 이번 달 인정 실적 집계 및 남은 목표액 실시간 계산
* **원터치 실적 기록:** 결제처, 결제금액, 실적 인정 여부(비인정 항목 체크) 간편 등록
* **월별 이용 이력 및 통계:** 카드별/월별 실적 달성 현황 및 히스토리 관리

### 3. ☕ 웰빙클럽 실적관리 (`/wellbeing`)
* **스포츠 & 컬처 멤버십 통합 관리:** 월간 이용 한도 및 승인 실적 추적
* **원터치 이용 등록:** 자주 가는 즐겨찾기 시설(헬스장 등) 원터치 등록
* **월별 이용 통계:** 총 이용 횟수, 잔여 횟수, 실질 혜택 금액 자동 집계

### 4. 🏢 아파트 임장 체크리스트 (`/apt`)
* **현장 임장 체크리스트:** 단지 환경, 교통, 학군, 채광, 수압 등 핵심 항목 점검
* **취득 비용 실시간 자동 계산:** 취득세, 중개보수(복비), 평당 단가 자동 환산
* **공유 및 기록 관리:** 임장 매물 목록 저장 및 카카오톡/메모장 전송용 텍스트 복사

### 5. 🚗 차량관리 (`/car`)
* **내 차 정비 & 소모품 수동 기록:** 엔진오일, 에어컨필터, 와이퍼, 타이어, 배터리, 브레이크 등 원터치 프리셋 등록
* **스마트 소모품 교체 주기 모니터링:** 주행거리(km) 및 기간(개월) 기반 권장 주기(양호/교체권장/교체요망) 한눈에 파악
* **누적 주행거리 간편 업데이트:** 계기판 주행거리 원터치 수정 및 정비 당시 주행거리 자동 연동
* **연간 정비 비용 및 이력 필터링:** 카테고리별 필터, 정비소 기록, 누적 정비 비용 자동 집계

## 🔒 데이터 보안 및 프라이버시

* **100% 로컬 프라이빗 저장:**
  * 모든 금융 자산 및 개인 메모 데이터는 외부 서버로 전송되지 않고 **오직 사용자의 스마트폰 내부(`LocalStorage`)에만 안전하게 보관**됩니다.
* **통합 데이터 백업 & 복원:**
  * 메인 홈 화면의 **[전체 백업]** 기능을 통해 모든 데이터를 단일 `.json` 파일로 스마트폰 다운로드 폴더에 안전하게 영구 보관할 수 있습니다.
  * 기기 변경 시 **[파일 복원]** 버튼으로 1초 만에 복구 가능합니다.

## 📱 스마트폰 PWA 설치 방법

1. 스마트폰 브라우저에서 배포된 GitHub Pages 주소 접속
   * **URL:** `https://kim-kyowon.github.io/kyowon_app/`
2. **홈 화면에 추가(앱 설치):**
   * **iOS (Safari):** 하단 중앙 [공유] $\rightarrow$ **[홈 화면에 추가]**
   * **Android (Chrome/삼성인터넷):** 우측 상단 더보기 $\rightarrow$ **[앱 설치]** 또는 **[홈 화면에 추가]**
3. 바탕화면에 생성된 앱 아이콘으로 실행하면 상/하단 브라우저 주소창 없이 전체 화면 네이티브 앱으로 구동됩니다.

## 🛠️ 기술 스택 및 디자인 원칙

* **Frontend:** HTML5, Modern Vanilla JavaScript (ES6+), Vanilla CSS
* **PWA:** Service Worker (`sw.js`), Web App Manifest (`manifest.json`)
* **Design:** Mobile-First, Minimalist, 단색 모던 인라인 SVG 아이콘
* **Hosting:** GitHub Pages
